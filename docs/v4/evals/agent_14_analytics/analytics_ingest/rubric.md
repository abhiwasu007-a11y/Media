# Judge rubric — `agent_14.analytics_ingest`

No LLM judge applies. `agent_14.analytics_ingest` contains no model call (blueprint §6), so this dataset has no subjective criteria. Every case is decided by the deterministic assertions I1–I7 in README §4; `judge_min` is `null` for every case. If a model call is ever added to this task type, it needs its own prompt file, a new dataset and a rubric by CCR (27 §4).
