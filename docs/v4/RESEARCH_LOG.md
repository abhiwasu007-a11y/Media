# Research Log

Single store of every external fact used in V4.0 (directive rule 3; owner rule A.11). Later documents cite an entry ID instead of re-researching.

**Status values.**
- **VERIFIED**: read on the official page on the date shown.
- **PARTIAL**: the core fact is verified and a named sub-point is not.
- **NOT CONFIRMED**: no official statement was found.
- **UNVERIFIED**: only secondary sources exist.
- **CONFLICT**: the official source contradicts a claim in the directive.

**Re-verification rule (plan Q18).** An entry is re-verified if it is more than 30 days old when it is used for a decision. All entries are re-verified once more before the build starts.

**Method.** Official pages were fetched and read directly (HTTP) on the check date. Search snippets and third-party blogs were used only to locate pages. Verification work was done by research sub-agents and reviewed before entry here.
