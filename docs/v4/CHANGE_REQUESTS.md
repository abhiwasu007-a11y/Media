# Change Requests (V4.1+)

The architecture freeze applies once the owner approves the V4.0 baseline (directive rule 11). From then on, any new idea is recorded here and **never** goes straight into the baseline documents.

Before approval, changes to the baseline are made directly in the draft documents, and the change is recorded in `IMPLEMENTATION_PROGRESS.md`.

## Rules
1. One row per idea. Link evidence such as research log IDs or measured data.
2. Decisions are *Accepted for V4.x*, *Rejected* or *Deferred*. Only the owner decides.
3. An accepted CR creates a backlog ticket. Baseline documents are updated only in the version that adopts it.
