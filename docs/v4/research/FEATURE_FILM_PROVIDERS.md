# Feature film providers: research findings and trailer cost estimate

Research for `FEATURE_FILM_PLAN.md` (owner D35, docs only). All pages read 2026-11-25 by research sub-agents from
official vendor pages; each row in the appendices carries its exact URL. Some pages were summarised by a fetch tool
or came from search extracts (marked in the rows): **re-read the exact page before any binding use or spend.**
Prices in USD as published; no currency conversion is made here.

## 1. What the research changes in the plan

1. **Google video.** Gemini API Veo 3.1 preview models were shut down on 2026-10-22; the Gemini API successor is
   Gemini Omni Flash 1.2 (3–15 s clips, extension to 30 s, up to 6 reference images, first/last frame, 1080p/4K
   upscale, native audio, about $0.104/s at 1080p). Vertex AI has Veo 3.1 GA (4/6/8 s, 3 reference images).
   **Only English speech is documented, and own audio cannot be supplied** → Hindi dialogue needs our own voices
   plus a separate lip-sync step (confirms plan §1.6).
2. **Google Flow has no API or export path** → manual creative workspace only (as both directives require).
3. **Sora API is shut down (2026-09-24)** → not a failover option.
4. **Failover candidates:** Kling 3.0 (character "elements" from 2–4 reference images, native audio, 3–15 s,
   $0.112/s 1080p without audio, $0.168/s with audio; API output terms NOT FOUND), Runway gen4.5 ($0.12/s, clear
   commercial use, motion transfer), Seedance 2.5 (widest references, $0.231–0.914/s, terms NOT FOUND), MiniMax.
5. **Actor reference images:** Gemini image models take up to 14 reference images; $0.039 per image
   (`gemini-2.5-flash-image`), Pro $0.134 (1K/2K).
6. **Hindi voices:** Google Chirp 3 HD hi-IN GA, free up to 1M characters/month then $30 per 1M, no emotion
   control; ElevenLabs eleven_v3 supports Hindi with audio tags (whisper, laugh, cry; Hindi reliability not stated),
   commercial use from Starter $6/month; Azure HD Hindi voices with styles (whisper, shout, sad) $22 per 1M chars;
   Sarvam Bulbul (licence terms NOT FOUND).
7. **Lip sync:** sync.so lipsync-2 $0.05/s (pro $0.083/s) plus plan fee, commercial clause NOT FOUND; open models:
   MuseTalk MIT (weights commercial-OK), LatentSync licence conflicting (Apache-2.0 vs openrail++), Wav2Lip
   non-commercial (excluded).
8. **Music:** Suno has **no official public API** (paid plans give output rights; manual step only); Udio not
   usable (downloads reported disabled); **ElevenLabs Music API excludes film/TV use** on paid plans; **Google
   Lyria 3.5 API $0.08/song** with vocals and lyrics in the prompt's language, commercial/YouTube terms NOT FOUND;
   YouTube Audio Library is monetizable for YPP members (background score fallback).
9. **Checks:** SpeechBrain ECAPA (voice similarity) Apache-2.0; **InsightFace models are non-commercial** →
   face-consistency check needs a commercially licensed model (open item).

## 2. Milestone 1 estimate: 60-second Hindi trailer (planning assumption, not a quote)

Assumptions (owner's own planning rules): 6 s average shot → 10 final shots; +50 % retries → 90 generated
seconds; about 30 s of dialogue needing lip sync (+50 % → 45 s); 4 actors × about 10 reference images.

| Item | Option | Arithmetic | USD |
|---|---|---|---|
| Video shots | Gemini Omni Flash 1.2, 1080p | 90 s × 0.104 | 9.36 |
| Video shots (alt.) | Kling 3.0, 1080p, no audio | 90 s × 0.112 | 10.08 |
| Video shots (alt.) | Runway gen4.5 | 90 s × 0.12 | 10.80 |
| Actor references | Gemini 2.5 Flash Image | 40 × 0.039 | 1.56 |
| Hindi voices | Google Chirp 3 HD | inside free 1M chars | 0 |
| Lip sync | sync.so lipsync-2 | 45 s × 0.05 (+ plan fee, not counted) | 2.25 |
| Music | Lyria 3.5 (terms to confirm) or YouTube Audio Library | 1–3 songs × 0.08 | ≤ 0.24 |
| Script, screenplay, checks | Anthropic (within D9 caps) | estimate | about 2 |
| **Total** | | | **about 15–17 + lip-sync plan fee** |

Full film, owner's 180-minute table (16,200 generated seconds), video only: Omni 1080p 16,200 × 0.104 ≈ $1,685;
Kling 1080p with audio 16,200 × 0.168 ≈ $2,722. Real numbers come from Milestone 1 (cost per accepted second).

## 3. Blockers before any spend (REQUIRES REVIEW)

India availability of Omni/Veo; Kling, Seedance and sync.so API commercial terms; Lyria commercial/YouTube terms;
a commercially licensed face-embedding model; LatentSync licence; Hindi quality of ElevenLabs tags; billing
accounts and keys (owner) for the chosen providers.
